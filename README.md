# Planner

- Firebase Email/Password login + Firestore sync
- Calendar with date-range events and separate start/end time
- WISH / BOUGHT wishlist with product metadata lookup
- Books and Movies sections in the left sidebar
- BOOKS: TO READ / READ
- MOVIES: TO WATCH / WATCHED
- Books and movies are displayed as image cards in a grid, like WISH
- Automatic title/creator/cover lookup with selectable search results and cover choices when available
- Manual fallback for creator and cover/image URL

## Firebase
Put your Firebase web config in `firebase-config.js`.
